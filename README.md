# NUS Buffet Response App 🍽️

A mobile app built with [Expo](https://expo.dev/) and React Native to reduce food waste by sharing leftover buffets in real time using geolocation.

## Features
- 📍 Post buffet locations with GPS
- 🔔 Notify users nearby
- 📱 Android + iOS support via Expo

## Getting Started

```bash
npm install
expo start
